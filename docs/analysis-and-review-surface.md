## DOM extension — 2026-10-17

The section below records the historical screenshot proposal, not the full current
surface. The implemented DOM extension preserves the current neutral/teal light
and dark themes and adds kind-specific source review beside screenshot review.
See [DOM snapshot checks](dom-snapshots.md) for the user workflow and
[verification](research/dom-snapshot-verification-20261017.md) for actual scope.

Both-mode evidence offers **Screenshots / DOM snapshot**; snapshot-only mounts no
image tools. Native inert unified source uses monospace only for literal code,
old/new line numbers and `+`/`−` alongside semantic color. Search, wrapped source,
collapsed-context expansion, change navigation and selection/copy stay in the
bounded evidence stage. Page/profile/source identity remains outside it.

Per-kind failures are visible beside a successful sibling. Decisions, notes,
Next unreviewed and approval selections use independent immutable analyses.
Confirmation identifies screenshots versus DOM and keeps selected versus inherited
references explicit. No active HTML/webview, automatic approval, new palette,
decorative asset or motion is introduced. Current native/OS/accessibility limits
are not superseded by backend or simulated input tests.

Mode: **Operate**, native desktop GPUI, not a mobile app. Extend the proposed
DESIGN.md system; no palette, typography or human visual approval is invented.

## Direction contract

**Thesis:** inspect actual retained evidence, then deliberately revise judgment
or references. Classification, review and capture coverage are separate.

**Own-world:** inherited near-white working surfaces, teal native actions,
system UI typography, straight list rules and compact controls. No decorative
charts, fake project imagery, confidence scores or animated processing theatre.

**Story:** choose a target, see its original before/after, inspect exact metrics,
adjust sensitivity, draw geometric ignored areas on either image, save a
revision-specific note, then preview acceptance with selected/inherited dates.

**First viewport:** project and capture actions, coverage-aware result inventory,
then an analysis/review section and synchronized tiled image panes. Advanced
numeric fields disclose units and criterion disabling. Overlay has a real pointer
slider with keyboard-accessible increment actions; region navigation is bounded
to the retained largest 16 while reporting all omitted regions.

**Form:** local extension of the existing results topology, precisely specified
by Phase 5; no new-world concept seed or brand replacement. Shared zoom/pan
coordinates are the signature interaction. Masks remain geometric, visible on
both images and pair/dimension-bound; source evidence is never stretched.

**Finish:** unreviewed and undocumented is unfinished; this build ends with the
finish review, the verdict, DESIGN.md, and every shipping raster carrying its
provenance.

## Finish disposition

The incumbent tokens/components remain unchanged. No shipping decorative raster
or new font asset was introduced; viewer imagery is the user's saved screenshot
evidence and exact derived significant-pixel heatmap. Source-based review and
simulated GPUI pointer/action tests are local implementer checks, not native,
accessibility or human approval. Historical blank native attempts are not
repeated. The required independent verifier/human visual finish review is pending;
the proposed composition is **not visually qualified**. No nested reviewer agent
was spawned under this task's explicit prohibition.
