**Thesis:** inspect actual retained evidence, then deliberately revise judgment
or references. Classification, review and capture coverage are separate.

**Own-world:** inherited near-white working surfaces, teal native actions,
system UI typography, straight list rules and compact controls. No decorative
charts, fake project imagery, confidence scores or animated processing theatre.

**Story:** choose a target, see its original before/after, inspect exact metrics,

revision-specific note, then preview acceptance with selected/inherited dates.

then an analysis/review section and synchronized tiled image panes. Advanced
numeric fields disclose units and criterion disabling. Overlay has a real pointer
slider with keyboard-accessible increment actions; region navigation is bounded
to the retained largest 16 while reporting all omitted regions.

by Phase 5; no new-world concept seed or brand replacement. Shared zoom/pan
coordinates are the signature interaction. Masks remain geometric, visible on
both images and pair/dimension-bound; source evidence is never stretched.

**Finish:** unreviewed and undocumented is unfinished; this build ends with the
finish review, the verdict, DESIGN.md, and every shipping raster carrying its
provenance.
