# Environment and login extension — Phase 4

Mode: **Operate**. Inherit the proposed DESIGN.md system; no new visual identity
or user approval is inferred. Native desktop GPUI, not a browser/webview replacement.

## Direction contract

**THESIS:** make environment, login readiness and incomplete coverage explicit,
without turning a release check into an automation console.

**OWN-WORLD:** existing bright working surface, teal actions, flat row structure,
semantic warning/error surfaces, system UI type and shared focusable controls.

**STORY:** save the chosen environment, approve its mappings, open the managed
browser, finish login/consent and confirm replay. Preview/probe mapped addresses
before checking the immutable baseline target list. Re-login is a recovery action,
not a visual difference or permission to broaden discovery.

**FIRST VIEWPORT:** existing shell/navigation and task heading remain. Setup groups
website/profile choices before environment/login details. Results keeps the fixed
inventory and coverage authoritative, with a compact saved-environment status and
login/probe actions. Large mapped inventories are bounded previews, not decorative
cards. Background work disables mutations without blocking navigation.

**FORM:** narrow extension of the established operational surface; no concept roll
or replacement brand. Secrets never enter labels, status, diagnostics or evidence.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish
review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Verification boundary

Simulated GPUI tests exercise real actions, focus and authoritative SQLite/background
completion. They do not qualify native pixels, keyboard/IME/clipboard/accessibility
or human comprehension. Prior native attempts were blank/unmapped; this phase does
not repeat black-window loops or claim approval. The independent verifier receives
this surface contract, source system and exact local test evidence. No new shipping
raster or font asset is authored; DESIGN.md remains an unapproved proposal.

## Finish disposition

The existing Operate layout, system type, flat rows and shared focus controls are
preserved. Warning codes now have plain-language labels; full-page limits and
incomplete/unstable rendering caution are explicit. Saved-environment actions and
draft guards are exercised against authoritative actor/storage replies.

Verdict: locally implemented, **not visually or human-accepted**. Native layout,
clipping, contrast at rendered sizes, input/accessibility and ordinary headed
login/consent still need the independent/native finish review; source and simulated
tests cannot decide those checks. DESIGN.md is unchanged. No shipping raster is
introduced; test PNGs are synthetic owned-loopback evidence with metadata/report
provenance, not product imagery or user approval.
