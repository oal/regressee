# Phase 0 bench — provisional surface, not Phase 1 brand

Operate mode. Synthetic screenshots are the visual subject; a restrained light
desktop print-preview bench keeps setup/login/capture actions above image evidence.
System UI type, slate text `#172b40`, ground `#f1f5f9`, white image field,
blue primary/focus `#1d4ed8`, boundaries `#64748b`/`#94a3b8`.
Base text 16 px, title 24 px, labels/status 14 px; toolbar spacing 8 px, main
groups 12 px, outer padding 20 px. Buttons use visible borders/focus and
ordinary-language labels; capture is the blue action. No animation is necessary
for this feasibility bench. Native titlebar, OS menu registration and file dialog
remain native instead of web imitations. Screenshot tiles are generated fixture
artifacts, never stock assets. `docs/spike-surface.md` records the development
direction and scope. Independent visual/accessibility review remains pending.

This documents built tokens, not an approved product design system. Screen-reader
semantics and default GPU reliability remain material gaps; keyboard operation
alone is not an accessibility pass. Do not start Phase 1 from assumed visual approval.
